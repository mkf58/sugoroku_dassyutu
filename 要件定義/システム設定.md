# 要件定義：ゲームシステム設定

本書は、「すごろく×魔女の館脱出ゲーム」のゲーム進行、盤面ルール、アイテム、魔法、エネミー、ステージ構成に関する確定事項をまとめた要件定義書である。

---

## 1. 基本システム・進行ルール

- **形式：** すごろく形式のターン制ボードゲームADV
- **開発エンジン・言語：** Godot Engine 4 (GDScript)
- **ターゲット環境：** PC (Steam / itch.io)
- **ターン構造：** 
  - プレイヤーターン（味方ユニットの行動選択・実行）
  - エネミーターン（魔女たちの移動・行動）
  - イベント解決フェーズ（マスイベント、接触判定、介錯、脱出など）
- **移動方式：** 
  - ダイスを振って出た目だけ進む。
  - **階段移動のみ（落とし穴は廃止）。**
- **敗北条件（ゲームオーバー）：** 
  - 主人公が魔女に捕まった場合、拷問ののち殺害され即ゲームオーバー。タイトル画面へ戻る。
- **セーブ方式：** 
  - 階層（ステージ）クリアごとのオートセーブ ＋ 任意セーブ機能。

## 3. キャラクターと魔法仕様

### (1) 味方ユニット（主人公・少女）共通の操作体系
- **バグ防止・操作統一方針：** 主人公および同行少女たち（全味方ユニット）は共通のコマンドインターフェースで操作する。
- **初期位置：** 全キャラクター（主人公・少女・エネミー）の初期配置マスはステージごとに固定。
- **操作権：** 味方は全員プレイヤー自身が指示を出して移動・アイテム・魔法を行使させる。
- **コマンド体系（各キャラクターの行動選択肢）：**
  1. **ダイスを振る（移動）：** 1〜6のダイスをロールし、出目分マスを前進する。
  2. **アイテムを使用する：** 共通インベントリから特殊ダイス（1〜6の賽、意志の賽、双子の賽など）を選択して使用・移動する（キャラごとの区別はなく共通所持品）。
  3. **魔法を使う：** 固有魔法を行使する。**魔法を使用したキャラクターはそのターン移動不可（移動と魔法の二者択一）**。MP等のコスト消費はなし。
  4. **ターンスキップ（待機・祈る）：** 何も行動せずそのターンを終了する。
  5. **コマンドを閉じる：** 盤面状況・敵配置を確認するためのUI開閉トグル。
- **少女の死亡と復活：** 魔女に捕まると殺害されるが、**3ターン後にそのステージの初期位置で復活**する。
- **地縛制限：** 少女たちは各自の殺害現場（担当フロア）に地縛されており、Stage 6およびエントランス以外の屋敷内部では、他フロアへ移動できない。

### (2) 各魔法の効果
| 属性 | 少女のエリア | 魔法効果 |
| :--- | :--- | :--- |
| **炎** | キッチン | 2マス以内にいる通常の魔女を倒す（倒された魔女は2ターン後に初期位置で復活）。 |
| **水** | 庭園 | 通過するのに1ターン余分にかかるマスを生成する（足止め）。 |
| **風** | 別邸・時計塔 | 自身の直線上にいる相手を最も遠いマスまで吹き飛ばす（自分自身も対象に可能）。 |
| **土** | 地下室 | 任意の相手を土に潜らせる（味方なら魔女をやり過ごし、魔女なら1ターン行動不能）。 |

### (3) 主人公の魔法習得（True Endルート）
- 逆走時に少女を介錯するごとに、その少女の魔法が主人公自身に移譲され、主人公が魔法を行使できるようになる。
- 主人公が魔法を使用する場合も同様に、魔法使用時はそのターンの移動は不可となる。
- Stage 1（2F）およびStage EXでは、主人公が4つの魔法を単独で使い分けることができる。

## 4. 介錯システム（True Endルート）

- **不可逆性：** 介錯は一度行うと取り消せない。
- **介錯の条件：** 
  - 少女を同行させた状態で、その少女の死因に対応した「特定の介錯マス」へ到達すること。
  - 炎：キッチンの焼却炉／大かまど
  - 水：庭園の古井戸
  - 風：時計塔の鐘楼
  - 土：地下墓所の墓穴
- **結果：** 少女は消滅（成仏準備）し、その魔法の力が主人公へと定着する。

## 5. エネミー（魔女）仕様

### (1) 配置と難易度方針
- **Stage 1（チュートリアル＆伏線）：**
  - 背後から追跡型が迫る緊迫感の中で1F階段を目指す。
  - 書斎側の脇道に周回型・感知型を配置し、行かなくても敵の行動ルールを自然学習できる構造。
- **Stage 2〜5（道中フロア）：**
  - 極端な難易度インフレは行わず、**ほぼ同水準のベース難易度**とする。
  - フロアごとに同行する魔法使いが異なるため、属性ごとの立ち回りで体験が変化する。
  - **逆走時の難易度変化：** 逆走時は主人公が各フロアで魔法を順次習得していくため、Stage 5（土）→ Stage 4（風）→ Stage 3（水）→ Stage 2（炎＋他3属性）へと戻るにつれて、自然に難易度が低下し、プレイヤーの「成長・無双感」が味わえる設計とする。
- **Stage 6 / Stage EX：**
  - クライマックスとして脱出・決戦に相応しい配置を行う。


### (2) 行動タイプ（エネミーAI）
1. **追跡型（ダイス移動）：**
   - 主人公を直接ターゲットにして最短距離で追跡する。
   - 毎ターンダイスを振って出た目（1〜6）だけ移動する。
2. **周回型（固定移動）：**
   - 決まったルート（特定の数マス間）を毎ターン一定歩数で往復・周回し続ける（ダイスは振らない）。
   - 通過タイミングを見極めるパズル要素。
3. **感知型（トラップ・直線急接近）：**
   - その場に留まるか狭い範囲を巡回している。
   - 自身の直線上の視界（一定マス内）に主人公が入った瞬間、感知して直線的に急接近してくる。

### (3) 干渉手段
- **炎の魔法：** 2マス以内にいる通常の魔女を一時的に撃破可能（2ターン後に初期位置で復活）。
- **水・風・土の魔法：** 足止め、吹き飛ばし、やり過ごしが可能。
- ※魔女のダイス出目や行動を直接書き換えるアイテムは存在しない。

## 6. アイテム仕様

- **インベントリ制限：** 所持数制限なし。
- **使用特性：** すべて使い捨て。

### (1) ダイス操作アイテム
| アイテム名 | 効果 | 主な入手方法 |
| :--- | :--- | :--- |
| **1の賽 〜 6の賽** | 使うと、対応した数字が必ず出る | アイテムマス（宝箱）でランダム入手 |
| **意志の賽** | 1〜6の中から好きな出目を自由に選べる | 石碑イベント等 |
| **双子の賽** | ダイスを2回振って合計した数だけ進む | 石碑イベント等 |

### (2) キーアイテム
| アイテム名 | 効果・役割 | 入手場所 |
| :--- | :--- | :--- |
| **書斎の鍵** | 2F書斎の扉を開けるための鍵 | Stage 6奥 または 逆走時に入手 |
| **正門の鍵** | エントランスの正面玄関を開けて脱出するための鍵 | 2F書斎（逆走時） |

## 7. マス（セル）の種類

1. **通常マス：** 何も起きないマス。
2. **アイテムマス（宝箱）：** 止まると「1〜6の賽」をランダムに入手。
3. **石碑マス：** 調べると世界観・過去の記録・ヒント（Normal Bエンドフラグ）が読め、特別な賽を入手。
4. **魔術の痕跡マス（True End用隠しフラグ）：** 
   - 魔女の初期配置位置など、「魔術の痕跡を探す」意識がないと踏まない場所に配置。
   - 止まると権力者の儀式研究メモの断片が手に入り、True End（説得フェイズ）の解放フラグとなる。
5. **解放マス（儀式の楔）：** Stage 6（墓地）に配置。止まると屋敷の結界を解く解放イベントが発生（少女4人が合流）。
   - **通常時（痕跡未回収）：** 選択肢は出ず、そのまま少女たちと共に裏口脱出（Normal End B）へ向かう。
   - **特殊時（全痕跡回収済み）：** 主人公が儀式の真相を告げて少女たちを説得するイベントが発生し、逆走ルートへ突入する（※初見プレイヤーに露骨な選択肢を見せず、隠しルートの存在を秘匿する演出）。

6. **介錯マス：** 各属性の死因に対応した場所（焼却炉・井戸・鐘楼・墓穴）。逆走時に少女を連れて止まると介錯イベントが発生。
7. **階段マス：** 次のフロア（逆走時は前のフロア）へ移動するマス。
8. **脱出マス：** 
   - Stage 6（裏口）：Normal End A（単独） / Normal End B（5人）の脱出マス。
   - Stage EX（正門）：True End の最終脱出マス（通常操作で到達してクリア）。

## 8. システム追加機能

1. **実績（Achievements）機能：**
   - エンディング到達（Normal A / Normal B / True End）、特定魔法の駆使、介錯の完遂、特定アイテムの収集など、ゲーム内の達成度を記録・閲覧できる機能。
2. **コンフィグ（設定）機能：**
   - BGM/SE音量調整、テキスト表示速度、メッセージスキップ等のプレイ環境設定。
3. **ステージ再探索（消費アイテム引き継ぎ）機能：**
   - クリア済みのステージに、所持している消費アイテム（ダイス類）を保持したまま戻り、取り逃したアイテムの回収や探索を行える機能。基本設計よりセーブデータ構造・状態管理に組み込む。
