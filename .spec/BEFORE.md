【企画・要件定義仕様書】魔女の館と双六の生贄（仮題）
1. プロジェクト概要
• タイトル（仮）: 魔女の館と双六の生贄 (Sacrifice & Dice in the Witch's Mansion)

• ジャンル: 2Dサイコホラー × バックトラック型ボードゲームADV

• 開発エンジン: Godot Engine 4 (GDScript) / AIエージェント共同開発

• ターゲット: Steam / PC (itch.io等)

2. コアバックストーリー＆世界観
• 悲劇の発端（権力者の儀式）: かつての権力者が「永遠の命」を得るため、魔女を凄惨な拷問の末に虐殺。その遺体と、魔女の実の娘たち（魔法使い）を生贄として捧げる禁忌の儀式を敢行した。

• 館の誕生と不死の呪い: 儀式の歪みにより母（魔女）の激しい怨念が空間そのものを侵食し、この「双六の館」が形成された。娘たちは死ぬこともできない「不死者」と化し、館の各フロアに地縛霊として囚われている。歴代の挑戦者たちは全員死亡しており、館の庭や地下に並ぶ無数の墓標は過去の犠牲者たちの成れの果て。

• 魔女の行動原理と忘却: 館を徘徊する魔女は本体ではなく「残留思念」。本来の目的は「不死の苦痛に苛まれる愛する娘たちを永遠の彷徨から解放する（完全に殺してあげる）こと」。しかし思念化により本来の目的を忘れ、自身が魔女狩りで受けた経験から「肉体を徹底的に損壊・解体すれば復活できないはずだ」という固定観念だけが残っている。結果として、目的を忘れたまま侵入者や娘を無差別に拷問・殺戮し続ける機械と化している。魔女の手（怨念の力）でいくら肉体を破壊しても呪いは解けず、娘たちは復活を繰り返す。

3. 表現・レーティングポリシー
• 対象レーティング: CERO:C / PG-12 相当

• ゴア表現の完全排除: 人体損壊、切断、直接的な流血スプラッターのグラフィック描画は全面禁止。

• 代替演出アプローチ:

  • 暗転と音響（フォーリー）: 捕縛時は画面が暗転。環境音のみで描写。製作技術があるならドットでアニメーションを用意してもいいが...

  • シルエット・オフスクリーン: 画面外での出来事として処理し、手前のアバターの怯え顔アイコン等で間接的に表現。

4. アセット調達・グラフィック演出仕様（暫定）
• 会話用立ち絵: 画像生成AI（透過PNG）。表情差分（通常、怯え、狂気、冷淡）を用意しADV会話枠で使用。

• イベントCG: 画像生成AI。人物の直接接触を避け、「無人の現場」「血のない儀式台」「霧の墓標」「ヒビ割れた陶器」等の情景・オブジェクト主体で生成。

• 洋館タイル・UI: itch.io / BOOTH。2Dトップダウン用の洋館内装・石碑タイルセット（Pixel Art）を調達。

• SE・BGM: フリー音源サイト（効果音ラボ等）。生々しい肉の音は排し、硬質な陶器破壊音、古びた扉の軋み、不穏なアンビエント音を使用。

• 盤面キャラクター（ドット絵アニメーション方針）: フレーム単位の手描き・連続コマAI生成による作画崩れを防ぐため、Godotノード駆動のハイブリッド方式を採用。

  • 基本形式: 32x32 または 48x48 のドット絵静止画。

  • 待機（Idle）: AnimationPlayer でスプライトの scale.y を微小に往復させ、呼吸・息づかいを表現。

  • マス移動（Jump）: Tween を用いて目標タイルへ放物線状に跳躍移動させ、着地時に一瞬潰す（スカッシュ＆ストレッチ）。

  • ダウン・捕縛: スプライトを横に90度パタンと倒し、小規模な破片パーティクル（GPUParticles2D）を発生。

5. ゲームシステム要件
• ターン進行ステートマシン (TurnManager): 1ターンは以下の4フェーズをループ。 Player Turn ──> Girl Turn ──> Witch Turn ──> Event Resolution

  • Player Turn: ダイスを振ってマスを進む。少女が同乗している場合は固有魔法・合流移動を選択可能。

  • Girl Turn: 独立したAIダイスで自律移動。

  • Witch Turn: ダイスまたは固定ルーティン（周回・定時突進）で移動。

  • Event Resolution: 同一マス判定（魔女による捕縛、プレイヤーによる解放/介錯、トラップ発動）。

• 盤面・マップグラフ (BoardGraph): マス目をノード、移動可能経路をエッジとした有向グラフ管理。

  • 通常床: 何も起きない。

  • 落とし穴: 下層フロアの対応するマスへ強制落下（知識によるバックトラックの重要経路）。

  • 石碑マス: 調べると謎解きヒント・世界観テキストを表示。

  • 浄化・祭壇マス: 特定アイテムを所持した状態で少女と重なると「解放」が可能。

• 魔女の行動バリエーション:

  • ダイス追跡型: プレイヤーや少女に向けてダイスを振って突進。

  • 周回巡回型: 外周や特定ルートを毎ターン固定マス（例: 3マスずつ）で規則正しく巡回。

  • トラップ感知型: 特定の条件マス（音の鳴る床、奇数マスなど）を踏んだ瞬間だけ急速接近。

6. エンディング分岐構造
初見では絶対に到達できず、しかし知識さえあれば1周目から実行可能な3分岐設計。

• Normal End A「閉じた輪」: 単身で脱出（アイテム不使用・少女未解放）。館を抜け出して外の墓場に出た瞬間、置き去りにされた少女たちが土の下から蘇り、脱出直前の主人公を取り囲んで殺害。「どうして私たちを置いていったの？」と引きずり込まれ、主人公の墓標が1つ増えてループが閉じる。

• Normal End B「災厄の解放」: 「屋敷の呪縛を解く鍵/聖杭（仮）」を使用して脱出。アイテムにより館全体の縛りが消え、各階の少女たちが最上階へ集結。全員で外へ脱出するが、同時に魔女を閉じ込めていた檻も消滅。魔女が現世へと解き放たれ、世界が厄災に呑まれる。

• True End「静かなる墓標（仮）」: 各階で少女たちを自らの手で「正しく介錯・解放」した上で脱出。少女たちの魂は安らかに成仏。最上階でアイテムを使おうとしても「呼応する魂はいない」と表示される。墓場には穏やかな朝が訪れ、魔女の怨念も消滅して真の生還を果たす。

• 重要アイテム仕様（仮置き）:

  • アイテム名（仮置き）: 屋敷の呪縛を解く鍵 / 聖杭（仮）

  • 入手場所: 最上階の寄り道マス（あやしい鏡などのオブジェクトマス）。

  • 表向きの効果: 館にかかる束縛の術式を解除し、各階に地縛されていた少女たちを呼び集めて脱出の助力を得られる。

  • 隠された真相: 少女の足枷を外すと同時に、館が持っていた「魔女を封じ込める結界」も完全に消滅する。

7. 開発マイルストーン
• Phase 1（最小コアロジック）: 直線20マスのダミー盤面作成。プレイヤー・少女・魔女の3コマによる交互ターン移動と接触判定の実装。

• Phase 2（演出プロトタイプ）: Godotの AnimationPlayer / Tween によるドット絵コマのピョンピョン移動・暗転SE演出の実装。

• Phase 3（ギミック・バックトラック実装）: 落とし穴による階層移動、石碑UI、少女の解放フラグシステムの実装。

• Phase 4（アセット統合・ブラッシュアップ）: AI生成立ち絵・CGの組み込み、バランス調整。
