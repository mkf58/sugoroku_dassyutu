# MEMORY

## プロジェクト概要
- タイトル（仮）：すごろく×魔女の館脱出
- ジャンル：ターン制すごろく脱出ホラー
- 目的：要件定義・基本設計・詳細設計・テスト駆動開発（TDD-WF）に沿ったゲームの完成

## 学習した知識・教訓
1. **ホラー作品の演出トーン：**
   - お涙頂戴や感傷的な演出を徹底して排し、冷徹に儀式を執行する乾いた質感を維持する。
   - 分岐選択肢を露骨に表示すると隠し要素がネタバレするため、条件達成時のみシームレスに特殊イベント（説得・逆走）を発生させる。
2. **難易度設計とゲーム体験：**
   - Stage 2〜5は同水準のベース難易度とし、属性魔法の個性を活かしたパズル的立ち回りで差別化する。
   - 逆走時は主人公が魔法を1つずつ習得していくため、戻るにつれて自然に難易度が下がり、プレイヤーの無双感・成長感が演出される。
3. **ドキュメント管理ルール：**
   - ストーリー設定（要件定義/ストーリー設定.md）とシステム設定（要件定義/システム設定.md）を明確に分離して要件定義書を管理する。
   - QAのログは必ず `.spec/PLAN.md` に残し、決定事項を速やかに要件定義書に反映する。
