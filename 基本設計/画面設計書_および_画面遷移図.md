# 基本設計書：画面設計・UIレイアウトおよび画面遷移図

本書は、「すごろく×魔女の館脱出ゲーム」（Godot Engine 4 / PC向け）における画面構成、マウス主体のUI操作体系、および画面遷移フローを定義した基本設計書である。実装後の**結合テスト仕様書（UI・画面遷移テスト）**へそのまま転用できる構成で記述する。

---

## 2. 操作体系仕様（マウス完全対応・ワンハンド操作）

PCでのプレイ快適性と没入感を最大化するため、キーボードを使わず**マウス操作のみ**で直感的に完結するインターフェースを採用する。

| 操作フェーズ | マウス入力 | 挙動・機能 |
| :--- | :--- | :--- |
| **常時（盤面操作）** | **ホイール回転** | **【画面の拡大・縮小】** マウスホイールの回転により、盤面カメラのズームイン / ズームアウト（0.5倍〜2.5倍）。 |
| | **中ボタンドラッグ** | **【画面スクロール】** 中ボタンドラッグ（または右ボタンドラッグ）で盤面カメラを自由にパン移動。 |
| **ターン開始時** | **左クリック** | コマンドメニューのボタンを選択・決定（初期位置で「ダイスを振る」に合致）。 |
| | **右クリック** | コマンドメニューを非表示にし、「盤面確認モード」へ移行（キャンセル/非表示）。 |
| **盤面確認モード** | **ホイール回転** | マップ全体のズームイン / ズームアウト（拡大・縮小）。 |
| | **右クリック** | マウスポインタ位置にコマンドメニューを再表示（復帰）。 |
| **移動先選択時** | **マウスホバー** | 移動可能（ハイライト表示中）なマスにカーソルを合わせると、自動生成された移動経路（点線矢印）をリアルタイムプレビュー表示。 |
| | **左クリック** | **【決定・1クリック移動】** ハイライトされた到達可能マスをクリックすると、中継マスの複数回クリックを一切必要とせず、即座に移動を開始。移動中に画面クリックで演出スキップ可能。 |
| | **右クリック** | **【キャンセル】** 移動先選択を取り消し、ダイス出目をリセットしてコマンドメニューへ戻る。 |
| **常時 / メニュー** | **コンフィグ呼出** | コマンドメニュー内の設定ボタン、または画面隅アイコンからConfigを開く（タイトル戻り可能）。 |

## 3. 画面一覧・詳細仕様

### (1) タイトル画面 (`TitleScreen`)
- **画面構成：**
  - **背景：** 霧に煙る洋館のシルエット、不穏なアンビエント音
  - **タイトルロゴ：** 『魔女の館と双六の生贄』（仮）
  - **メニューボタン一覧：**
    1. `はじめから`（新規ゲーム開始 → Stage 1 OPへ）
    2. `つづきから`（最新クリアセーブから再開：未クリア時は次ステージ直行、クリア済み時はステージ選択へ）
    3. `実績確認`（獲得した実績一覧モーダルを開く）
    4. `コンフィグ`（設定モーダルを開く）
    5. `ゲーム終了`（ウィンドウを閉じる）

---

### (2) メインゲーム盤面画面 (`MainGameScreen`)

解像度：1920x1080（ベース） / 16:9比率

```
+-------------------------------------------------------------------------------+
| [フロア情報: Stage 2 - 1F キッチン]  [ターン数: 05]              [コンフィグ] |
+-------------------------------------------------------------------------------+
|                                                                               |
|                             [2D グリッド盤面表示]                             |
|                                                                               |
|                   ・操作対象キャラが淡く発光（他キャラはディマー）            |
|                   ・マウス位置にコマンドポップアップ出現                      |
|                                                                               |
|                      +------------------------+                               |
|                      | 【コマンド】           |                               |
|                      |  [1. ダイスを振る] <-- |  (初期フォーカス)             |
|                      |  [2. アイテム]         |                               |
|                      |  [3. 魔法を使う]       |                               |
|                      |  [4. 祈る]             |                               |
|                      |  [右クリック: 閉じる]  |                               |
|                      +------------------------+                               |
|                                                                               |
|                   ・移動時は移動可能マスが淡く発光ハイライト                  |
|                   ・左ドラッグでマップスクロール、ホイールでズーム            |
|                                                                               |
+-------------------------------------------------------------------------------+
| 【ログ / メッセージウィンドウ】                                               |
| 「炎の少女のターン：炎の魔法を行使した！ 魔女を撃破！」                       |
+-------------------------------------------------------------------------------+
```

#### ① 操作演出・視覚フィードバック
- **アクティブキャラの発光：** プレイヤーターン開始時、現在操作中のキャラクターコマが淡い光（アウトライン/グロー）を放ち、未操作の味方やエネミーはやや暗く減光（ディマー）されてフォーカスを明示。
- **移動マスのハイライト：** ダイス出目決定後、到達可能な候補マスが淡く発光し、プレイヤーの直感的なルート選択を支援。
- **追跡型魔女のターゲット表示：** 追跡型魔女の頭上に、現在狙っている対象キャラのミニアイコンを表示。ターゲットが切り替わった瞬間（自分になった時、外れた時）に軽微な切替エフェクトと警告SEを再生（移動距離予告は過剰なため行わない）。
- **危険範囲への接近警告演出：** プレイヤーターン中、感知型や周回型エネミーの「次ターンの移動予測範囲・感知視界」に足を踏み入れた（または移動ルートが重なった）際、**心拍音（ドクン…という心臓の拍動SE）とともに画面周辺が黒くビネット減光する演出**を発生させ、プレイヤーに直感的な危機を伝える。
- **ドット絵演出：** コマはGodotのTweenによる放物線ジャンプでマス間を移動。
- **味方移動アニメーションの短縮・スキップ：** 移動中に画面を左クリックするとTweenアニメーションを即座にスキップし、一瞬で停止マスへ到達してイベント解決へ移行。
- **エネミーターン演出スキップ：** エネミーターン時、捕縛や少女殺害が発生しない通常移動であれば、一瞬（即時移動）で全エネミーの移動を完了させてプレイヤーターンへ復帰。

#### ② ダイアログ・イベントモーダル (`DialogueEventModal`)
- 石碑の調査、魔術の痕跡発見、解放イベント、介錯イベント時に中央へオーバーレイ表示。
- ADV風の枠、テキスト送り（クリックで即時全表示・ページ送り）、顔アイコン／イベントイラストの表示。

#### ③ 捕縛演出 (`GameOverCutscene`)
- 魔女と主人公が同一マスになった瞬間に発動。
- 画面が完全暗転し、不穏な環境音・陶器破壊音・衣擦れのSEのみが再生される（ゴア描画は排除）。
- コンフィグで「死亡演出スキップ」が有効な場合、または暗転中に画面をクリックした場合は即座にカットされ、下記のゲームオーバー画面へ直接遷移する。

### (3) ゲームオーバー画面 (`GameOverScreen`)

捕縛・死亡演出終了後に遷移する専用リザルト画面。

```
+-------------------------------------------------------------------------------+
|                                                                               |
|                                                                               |
|                            [ 魔女に捕縛された… ]                              |
|                                                                               |
|                     Stage 2 - 1F キッチン (生存ターン: 07)                    |
|                        死因: 追跡する魔女の手に落ちた                         |
|                                                                               |
|                                                                               |
|                     +-----------------------------------+                     |
|                     |  [1. この階層をやり直す] <--------- | (初期フォーカス)  |
|                     |  [2. タイトルへ戻る]              |                     |
|                     +-----------------------------------+                     |
|                                                                               |
|                                                                               |
+-------------------------------------------------------------------------------+
```

- **画面構成・UIレイアウト：**
  - **背景：** 完全な静寂または低音アンビエント。暗闇の中に洋館の床と残されたダイスの寂寥感あるグラフィック。
  - **メッセージ：** 「魔女に捕縛された…」のホラー調テキスト。
  - **リザルト情報：** 挑戦していたステージ名、生存ターン数、死因を表示。
  - **選択ボタン：**
    1. `この階層をやり直す`（初期フォーカス。マウスクリックで直ちに該当ステージの初期配置・ターン1へロード再突入）。
    2. `タイトルへ戻る`（タイトル画面へ遷移）。

---

### (4) ステージ選択画面 (`StageSelectScreen`)（クリア済み周回・再探索）
- **解放条件：** 一度いずれかのエンディングに到達したクリアセーブデータのみ遷移可能。
- **画面仕様：**
  - 解放済みのステージ（Stage 1〜Stage 6）を一覧表示。
  - **探索のミステリー性を保持するため、石碑既読率・痕跡回収率・宝箱回収率はあえて非表示**とする。
  - **宝箱のリスポーン：** ステージに入るたびに宝箱マスは復活し、何度でも開けて賽アイテムを補充・回収できる。
  - 所持している消費アイテム（1〜6の賽など）を保持したまま、目的のステージを選択して出撃する。

---

### (5) コンフィグモーダル (`ConfigModal`)
- ゲーム中（盤面）およびタイトル画面の双方から呼び出し可能。
- **設定項目：**
  - マスター音量、BGM音量、SE音量スライダー（0〜100%）。
  - テキスト送り速度（低速 / 標準 / 高速 / 瞬間表示）。
  - 画面モード（フルスクリーン / ウィンドウ表示）。
  - **死亡演出スキップ：** （OFF [演出をすべて見る] / 既読のみスキップ / 常にスキップ）
  - **味方移動アニメーション：** （通常 / クリックでスキップ / 常にスキップ）
  - **敵移動アニメーション：** （通常 / 常にスキップ）
  - `タイトルへ戻る`（ゲーム中モーダルのみ表示。セーブはステージクリア時のみのため、確認ダイアログを挟む）。

---

### (6) ヘルプモーダル (`HelpModal`)（遊び方・マス効果一覧）
- タイトル画面およびゲーム中盤面のメニューからいつでもワンクリックで呼び出し可能。
- 盤面ホバー時の邪魔なポップアップ（画面のチラつき）を排除し、プレイヤーが必要な時だけ落ち着いて確認できる仕様とする。
- **掲載内容：**
  - **マス種別と効果一覧：**
    - `EVENT`（宝箱、石碑、魔術痕跡、儀式解放、介錯）
    - `ADDITIONAL_MOVE`（追加移動：指定歩数さらに進む）
    - `RETURN_TO_START`（振り出し：スタート地点へ戻る）
    - `SKIP_TURN`（1回休み：次ターン行動不能）
    - `ROLL_AGAIN`（もう一度：即座に再行動）
    - `WATER_TRAP`（水魔術トラップ：侵入時に強制停止・ターン終了）
    - `EXIT`（階段・脱出口）
  - **基本ルール・操作説明：**
    - 魔女の追跡ルール（最短距離優先、同距離時の優先順位）
    - 味方の魔法の使い方と効果
    - マウス操作一覧（左クリック決定、右クリックキャンセル、左ドラッグマップ移動）

## 4. 結合テスト仕様への転用観点（画面遷移・UIテスト）

| テスト項目ID | テスト対象画面 | 操作・入力条件 | 期待されるUI挙動 |
| :--- | :--- | :--- | :--- |
| **IT-UI-001** | タイトル画面 | `はじめから` 押下 | プロローグイベント（暗転テキスト）を経てStage 1へ遷移すること |
| **IT-UI-002** | タイトル画面 | `つづきから` 押下（未クリア時） | ステージ選択を挟まず、直前のクリア後次ステージへ直接遷移すること |
| **IT-UI-003** | タイトル画面 | `つづきから` 押下（クリア済み時） | ステージ選択画面（再探索）へ遷移すること |
| **IT-UI-004** | メインゲーム盤面 | ターン開始 | 操作キャラが発光し、マウス位置にコマンドメニューが出現すること |
| **IT-UI-005** | メインゲーム盤面 | コマンド表示中に右クリック | コマンドメニューが非表示になり、盤面確認モードへ移行すること |
| **IT-UI-006** | 盤面確認モード | 左ボタンドラッグ / ホイール | マップが滑らかにスクロールし、ホイールで拡大縮小できること |
| **IT-UI-007** | 盤面確認モード | 右クリック | マウスポインタ位置にコマンドメニューが再表示されること |
| **IT-UI-008** | メインゲーム盤面 | ダイス出目決定後 | 移動可能マスが発光し、ホバーで経路プレビュー、左クリックで移動決定、右クリックでキャンセルできること |
| **IT-UI-009** | メインゲーム盤面 | コンフィグからタイトル戻る | 確認ダイアログを経てタイトル画面へ正しく遷移すること |
| **IT-UI-010** | メインゲーム盤面 | 主人公が魔女と同マス（未潜行） | 画面が完全暗転し、捕縛SE再生後、ゲームオーバーダイアログが表示されること |
| **IT-UI-011** | ステージ選択画面 | ステージ再突入 | 所持消費アイテムが維持され、宝箱マスが未開封状態で配置されること |
| **IT-UI-012** | メインゲーム盤面 | 魔女のターゲット更新時 | 魔女頭上アイコンが更新され、切替エフェクト・警告SEが再生されること |
| **IT-UI-013** | メインゲーム盤面 | 感知・周回エネミーの危険域に足を踏み入れた時 | 心拍SEが再生され、画面周辺に黒いビネット減光演出が発生すること |
| **IT-UI-014** | メインゲーム盤面 | 味方コマ移動中に左クリック | Tween演出が即座に中断され、目的マスへ瞬間移動してイベント処理へ移行すること |
| **IT-UI-015** | メインゲーム盤面 | エネミーターン開始（捕縛なし時） | （スキップ設定時）全エネミーが一瞬で目的マスへ移動完了し、プレイヤーターンへ戻ること |
| **IT-UI-016** | タイトル/メイン盤面 | ヘルプボタン押下 | ヘルプモーダルが開き、マス効果一覧および基本ルールが確認できること |
