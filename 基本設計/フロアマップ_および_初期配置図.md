# 基本設計書：フロアマップおよび初期配置図

本書は、「すごろく×魔女の館脱出ゲーム」における各フロア（Stage 1〜Stage 6）の盤面構造、マス種別、主人公・少女・魔女の初期配置座標を視覚的に作図・解説した設計ドキュメントである。
起動前に各フロアの配置・ルート・障害物状況を一目で確認できるリファレンスとして用いる。

---

## 1. 共通マス種別・凡例一覧

| 記号 | マス種別 (CellType) | 停止時効果 / 役割 |
| :---: | :--- | :--- |
| **`[ S ]`** | **主人公初期位置** (`HERO`) | 主人公が最初に出発するマス（通常マス） |
| **`[ G ]`** | **少女初期位置** (`GIRL_*`) | 各階層で同行する少女が出発するマス（通常マス・北回廊控室） |
| **`[ W ]`** | **魔女初期位置** (`WITCH_*`) | 各階層を徘徊する魔女の初期出現マス |
| **`[ N ]`** | **通常マス** (`NORMAL`) | 通常の白マス。イベントなし |
| **`[+2]`** | **追加移動マス** (`ADDITIONAL_MOVE`) | 停止時、即座に追加で+2マス移動できる |
| **`[ E ]`** | **イベントマス** (`EVENT`) | 停止時、宝箱（固定ダイスアイテム入手）等のイベントが発動 |
| **`[再]`** | **もう一度マス** (`ROLL_AGAIN`) | 停止時、その場でダイスをもう1回振って移動できる |
| **`[休]`** | **1回休みマス** (`SKIP_TURN`) | 停止時、次のターン行動不能（スキップ）になる |
| **`[振]`** | **振り出しマス** (`RETURN_TO_START`) | 停止時、そのステージのスタート初期位置へ強制送還される |
| **`[水]`** | **水トラップマス** (`WATER_TRAP`) | 踏んだ瞬間に残歩数破棄・即ターンエンド（魔女も同様に即停止） |
| **`[GOAL]`** | **出口マス** (`EXIT`) | 停止（または出目余り到達）でステージクリア・次フロアへ遷移 |

## 2. テンプレート盤面構造図（グリッド座標系）

館の基本構造は、中央の大廊下（メインストリート）と、南北の脇回廊（ショートカット・宝物庫）を複数の連絡通路で繋ぐ回廊構造である。

```
        X=1   X=2   X=3   X=4   X=5   X=6   X=7   X=8   X=9   X=10  X=11  X=12  X=13  X=14
Y=1:               [ G ]--[ N ]--[ E ]--[ N ]--[再]--[ N ]--[水]--[ N ]--[ E ]
                     |                             |                             |
Y=2:               [ N ]                         [ N ]                         [ N ]
                     |                             |                             |
Y=3:   [ S ]-[ N ]-[ N ]--[休]--[ N ]--[水]--[ N ]--[ N ]--[+2]--[ N ]--[ N ]--[ W ]-[ N ]-[GOAL]
                     |                             |                             |
Y=4:               [ N ]                         [ N ]                         [ N ]
                     |                             |                             |
Y=5:               [ E ]--[ N ]--[振]--[ N ]--[+2]--[ N ]--[再]--[ N ]--[ E ]
```

### 【初期配置の衝突・道詰まり防止設計】
1. **主人公と少女の初期配置分離：**
   - 主人公は中央ストリート入口 **`(1, 3)`** からスタート。
   - 少女は北側回廊の控室 **`(3, 1)`** からスタート。
   - これにより、序盤の一本道（X=1〜X=3）を少女が塞ぐことがなく、主人公は出目1〜6に関わらず自由に直進・分岐を選択可能。
2. **味方マスの最終停止禁止（重なり不可）ルール：**
   - 移動計算時、生存している他の味方ユニットがいるマスは「通過（飛び越え）」可能だが、「最終停止」の到達可能マスからは自動除外される。
3. **未潜行魔女の進入禁止障害物化：**
   - 未潜行の魔女 `(12, 3)` がいるマスは進入禁止障害物として計算されるため、プレイヤーが魔女マスを踏んで理不尽に捕縛されることはない。

### Stage 3: 庭園・古井戸
- **テーマ：** 雨に濡れた中庭と古井戸。水の少女と合流。
- **同行少女：** `GIRL_WATER`（水の少女 / 水魔術：現在地に水トラップ設置）
- **魔女：** `WITCH_3`（追跡型）

- **配置座標一覧：**
  - 主人公 (`HERO`): `(1, 3)`（中庭アーチ入口）
  - 水の少女 (`GIRL_WATER`): **`(3, 1)`**（北側回廊・水汲み場）
  - 魔女 (`WITCH_3`): `(12, 3)`
  - EXIT (`EXIT`): `(14, 3)`
- **攻略ポイント：**
  - 狭い一本道や連絡通路に「水魔術」で水トラップを設置することで、追跡してくる魔女を確実に1ターン足止めできる。

### Stage 6: 裏口・墓地（最終脱出階層）
- **テーマ：** 過去の挑戦者の墓標が並ぶ地上墓地。最終脱出地点。
- **同行少女：** なし（解放前）※寄り道でBアイテム使用時のみ全員解放
- **魔女：** `WITCH_6`（追跡型）

- **配置座標一覧：**
  - 主人公 (`HERO`): `(1, 3)`（地下からの出口）
  - 魔女 (`WITCH_6`): `(12, 3)`
  - EXIT (`EXIT`): `(14, 3)`（館の裏門脱出口）
- **攻略ポイント：**
  - 寄り道マスで「儀式の楔」を回収して脱出するか（Normal End B）、石碑で真相を知り逆走を選択するか（True Endルート）。

## 4. 起動前確認チェックリスト

| 確認項目 | 判定条件 | 状態 |
| :--- | :--- | :---: |
| 全ユニット初期座標の盤面存在性 | 全ステージの `hero_coord`, `companions[].coord`, `enemies[].coord` が `board.has_cell()` を満たす | **OK (UT-STAGE-N04)** |
| 初期配置での道塞がり防止 | 主人公 `(1, 3)` と少女 `(3, 1)` が別ルートに配置され、X=1〜3が塞がれていない | **OK** |
| 味方マスの最終停止禁止 | 他の味方ユニットの現在地マスにはダイス移動で最終停止できない（通過のみ可能） | **OK** |
| 未潜行魔女の進入禁止化 | 到達可能マス計算時に魔女マスが除外され、移動中の接触死が防止されている | **OK** |
