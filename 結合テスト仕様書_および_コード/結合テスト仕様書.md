# 結合テスト仕様書 (Integration Test Specification)

## 1. 概要・基本方針
本ドキュメントは、プロジェクト「すごろく×魔女の館脱出」における結合テスト（Integration Test: IT）の仕様を定義するものである。
基本設計書（[ゲーム進行_および_ターン制御フロー設計書.md](file:///c:/Users/mkf11/antigravity_base/sugoroku_dassyutu/基本設計/ゲーム進行_および_ターン制御フロー設計書.md)、[データ構造_および_モデル設計書.md](file:///c:/Users/mkf11/antigravity_base/sugoroku_dassyutu/基本設計/データ構造_および_モデル設計書.md)、[画面設計書_および_画面遷移図.md](file:///c:/Users/mkf11/antigravity_base/sugoroku_dassyutu/基本設計/画面設計書_および_画面遷移図.md)）で定義された結合テスト観点を網羅し、各コンポーネント（ターン制御、データモデル、UI・入力制御）の相互連携が意図通りに機能することを自動テストコードにより担保する。

### 1.1 テストレベルの定義と単体テスト（UT）との差異
- **単体テスト（UT / `実装コード/tests/`）：**
  - 各クラス・関数の独立した入出力、計算ロジック（BFS経路探索、最短距離計算、状態Enum値）の正当性を検証。
- **結合テスト（IT / `結合テスト仕様書_および_コード/`）：**
  - 複数クラス（`TurnManager` + `GridBoard` + `MainGame` + `ActionCommandMenu` 等）を実動させ、シグナル発火、イベント連鎖、1歩ごとのリアルタイム接触判定、画面状態遷移、UIバック操作（`_go_back`）が一連のフローとして正しく成立することを検証。

## 2. 結合テスト実行環境と構成

### 2.1 テストコード構成
| スイートID | テストスクリプト | 対象領域・観点 |
| :--- | :--- | :--- |
| **IT-TRN** | `test_it_turn_progression.gd` | ターン制御・移動判定・トラップ即時停止・ギミック連鎖・魔女AI追跡 |
| **IT-DAT** | `test_it_board_data.gd` | 盤面データ接続・視界走査・インベントリ整合性・特殊マスデータ |
| **IT-UI** | `test_it_ui_flow.gd` | UI状態遷移・コマンドメニュー・モーダル開閉・右クリックバック・出目確定後キャンセル不可 |
| **RUNNER** | `integration_test_runner.gd` | ヘッドレス環境下で全結合テストスイートを実行・集計するランナー |

### 2.2 実行方法
#### ローカル（Godot CLI）または CI（GitHub Actions）
```bash
# ヘッドレスモードで結合テストを一括実行（終了コード 0: 成功, 1: 失敗）
godot --headless --path 実装コード -s ../結合テスト仕様書_および_コード/integration_test_runner.gd
```
